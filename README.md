# FitFuel — 健身飲食規劃師

純靜態的健身飲食規劃 Web App，使用 Nexus 深色設計系統與繁體中文界面。無需後端，所有資料儲存於記憶體中（重新整理頁面即重置）。

## 使用方式

直接以瀏覽器開啟 `index.html` 即可。

## 功能

- **個人化飲食計劃**：依年齡、體重、身高、性別、活動量與健身目標（減脂／增肌／維持／重組）計算每日營養目標並生成 7 天三餐計劃。
- **食物資料庫搜尋**：搜尋額外食材，顯示每 100g 的卡路里、蛋白質、碳水、脂肪，輸入克數後加入當日計劃並計入總計。
- **自定義食譜導入**：可手動貼上或直接導入 JSON 檔案（支援點擊選擇、拖放，以及下載範本），系統自動比對食物資料庫並分析卡路里與巨量營養素，加入當日計劃。JSON 格式：`{ "name": "...", "ingredients": [{"name":"雞胸肉","grams":150}], "steps": ["..."] }`，`ingredients` 亦可為字串如 `"雞胸肉 150g"`，並支援中文鍵（名稱／食材／步驟）。
- **自定義餐食紀錄**：手動輸入餐食名稱、熱量與巨量營養素（未填熱量時以 4/4/9 估算）。
- **每週報告**：統計 7 天平均攝取量並與目標比較，以圓餅圖顯示整體達成率。
- **PDF 匯出**：將當日飲食計劃（含食材清單與烹飪步驟）以可打印格式匯出。

## 技術

純 HTML / CSS / JavaScript 單檔實作，無任何後端與外部執行依賴（僅引用 Google Fonts）。
