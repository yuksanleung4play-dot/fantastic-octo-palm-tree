# 首爾質感傢俬探店地圖 ｜ 聖水洞 × 漢南洞

一個純前端、可離線開啟的本地網頁，整理首爾 **聖水洞 (성수동)** 與 **漢南洞 (한남동)** 的質感傢俬店、選物店與傢俱陳列室探店地圖。

## 功能

- **雙區域切換**：聖水洞 / 漢南洞 一鍵切換。
- **必逛店家卡片**：每間店附上
  - 📍 詳細地址（中文 + 韓文原文，方便貼進 Naver Map）
  - 🎨 特色風格描述與亮點標籤
  - 🕒 營業時間
  - 💰 預估購物預算與級距（₩ / ₩₩ / ₩₩₩）
- **示意探店地圖**：SVG 街道地圖標記每間店的順序編號，點選地圖標記或卡片可互相對應高亮。
- **步行路線建議**：依最順暢動線排序，並標示各站之間的概略步行時間。
- **類型篩選**：選物店 / 傢俱陳列室 / 複合空間 快速過濾。
- **預算速覽**：一眼看懂三種價位級距。
- **響應式設計**：手機、平板、桌機皆可順暢瀏覽。

## 如何使用

不需任何伺服器或安裝，直接用瀏覽器開啟 `index.html` 即可：

```bash
# macOS
open index.html
# Linux
xdg-open index.html
# 或直接把 index.html 拖進瀏覽器視窗
```

## 檔案結構

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 頁面結構 |
| `styles.css` | 視覺樣式（暖色調、地圖、卡片、響應式） |
| `data.js` | 兩區店家與路線資料，可自行增修 |
| `app.js` | 互動邏輯（切換、篩選、地圖、路線高亮） |

## 想新增 / 修改店家？

編輯 `data.js` 中對應區域的 `shops` 陣列即可，欄位說明：

- `order`：路線順序（同時用於地圖編號）
- `name` / `nameKo`：中文店名 / 韓文店名
- `category`：`選物店` ｜ `傢俱陳列室` ｜ `複合空間`
- `address` / `style` / `hours` / `budget`：地址 / 風格 / 營業時間 / 預算
- `highlights`：亮點標籤陣列
- `priceTier`：`1`（親民）｜`2`（中階）｜`3`（高階）
- `x` / `y`：在示意地圖上的座標（viewBox 為 `0 0 960 640`）

## 免責聲明

地址、營業時間與預算為整理彙編之**參考值**，店家可能臨時公休或調整資訊。
出發前請以 **Naver Map** 與店家官方 **Instagram** 為準。
