# 部門更表模版（跨年）

Excel 部門輪班更表模版，換年只需改「顯示年份」並更新公眾假期清單，無需重做整份表格。

## 檔案

- `部門更表模版_跨年.xlsx` — 可直接開啟使用的模版
- `create_roster.py` — 產生／重建該 xlsx 的腳本（可選）

## 工作表

| 工作表 | 用途 |
|--------|------|
| 排班表 | 本週／下週快覽、全年週份排班、年假／補假統計、衝突標紅 |
| 設定 | 顯示年份、輪班基準日、六人姓名／類型／Offset／**個人年假額度** |
| 請假登記 | **唯一**請假輸入源（姓名＋日期＋AL/SL 清單） |
| 本月排班日曆 | 當月日曆純檢視（公式自動；請勿輸入） |
| 假期上班登記 | 公眾假期上班人員登記＋補假統計 |
| 公眾假期 | 每年追加假期日期與名稱 |
| 使用提示 | 操作指引 |

## 快速開始

1. 開啟 `部門更表模版_跨年.xlsx`
2. 在「設定」確認顯示年份、人員與各人年假額度
3. 請假只在「請假登記」逐日新增列
4. 公眾假期仍上班：到「假期上班登記」用下拉選擇人員
5. 看當月細節：開「本月排班日曆」（唯讀）
6. 每年年頭：改顯示年份 + 在「公眾假期」追加新假期（**不要改**輪班基準日 2026-06-29）

詳見工作簿內「使用提示」工作表。
