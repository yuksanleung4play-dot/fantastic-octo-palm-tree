# 部門更表模版（跨年）

Excel 部門輪班更表模版，換年只需改「顯示年份」並更新公眾假期清單，無需重做整份表格。

## 檔案

- `部門更表模版_跨年.xlsx` — 可直接開啟使用的模版
- `create_roster.py` — 產生／重建該 xlsx 的腳本（可選）

## 工作表

| 工作表 | 用途 |
|--------|------|
| 排班表 | 本週／下週快覽、全年 52/53 週排班、統計與衝突標紅 |
| 設定 | 顯示年份、輪班基準日、年假額度、六人姓名／類型／Offset |
| 請假登錄 | 在對應人員×週份格輸入 AL／SL |
| 公眾假期 | 每年追加假期日期與名稱 |
| 使用說明 | 操作指引 |

## 快速開始

1. 開啟 `部門更表模版_跨年.xlsx`
2. 在「設定」確認顯示年份與人員
3. 請假請到「請假登錄」填 AL 或 SL
4. 每年年頭：改顯示年份 + 在「公眾假期」追加新假期（**不要改**輪班基準日 2026-06-29）

詳見工作簿內「使用說明」工作表。
